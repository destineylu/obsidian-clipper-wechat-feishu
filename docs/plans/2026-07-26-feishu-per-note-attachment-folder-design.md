# 飞书附件按笔记分类设计

## 目标

飞书剪藏产生的图片、视频和其他附件统一保存到当前笔记对应的目录：

```text
Attachments/Web Clipper/<笔记名>/
```

同一笔记的不同媒体类型不再拆分子目录，方便在 Obsidian 文件列表中集中查找。

## 路径规则

- 使用保存请求中笔记路径的最后一段，并移除 `.md` 后缀。
- 替换 Windows、Obsidian 和 Markdown 路径中的不安全字符。
- 附件文件名继续保留事务短标识和序号，避免同名覆盖。
- Markdown 中的附件引用使用配套插件最终预留的 Vault 路径。

## 兼容性

- 新建下载和插件重启后恢复的未完成会话使用按笔记分类的新目录。
- 已经写入 Vault 的历史附件不移动，避免破坏旧笔记引用。
- 配置中的附件根目录仍然有效；只在该根目录下增加笔记名子目录。

## 验证

- 验证图片、视频和文件进入同一个笔记目录。
- 验证笔记名中的路径敏感字符会被安全替换。
- 验证 Markdown 引用与实际二进制文件路径一致。
- 运行配套插件类型检查、专项测试、全量检查和构建。
